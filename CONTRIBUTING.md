# Contributing

Thank you for contributing to MenüQR Bridge.

## Before opening a pull request

1. Open an issue for substantial behavior, protocol, security, dependency, or
   architecture changes.
2. Keep changes focused and avoid unrelated generated output.
3. Add or update tests for behavior changes.
4. Run the relevant checks documented in [README.md](README.md).
5. Confirm that no secrets, customer data, printer addresses, diagnostics, or
   generated installers are included.

## Review and release policy

External contributions require review by a project maintainer before merge.
Release-signing changes, dependency updates, installer changes, and security
boundary changes require explicit maintainer approval. Contributors and
maintainers must use multi-factor authentication for GitHub access.

Security reports must use the private process in [SECURITY.md](SECURITY.md).
Submitting a pull request indicates that the contribution is provided under the
Apache License 2.0.
